# Olist-E-commerce-Data-Analysis
Data analysis on Olist E-commerce dataset
This project contains an analysis of the *Olist E-commerce dataset* using *Excel* and *Power BI*.  
The goal is to explore customer behavior, order trends, payment methods, and other insights to understand the e-commerce business better.

## Project Overview
- Analyze customer orders and purchasing patterns using Excel  
- Examine payment types and trends  
- Explore geolocation of customers and sellers  
- Visualize insights using Power BI dashboards
